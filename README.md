# Sonic-FX

Français - FR

Sonic FX est un jeu FanGame de la licence Sonic The Hedgehog.
Le projet est open source et est disponible pour tous.
Le moteur utilisé est sous Unity avec le code source "The Bumper Engine" de SuperSonic68.

Le projet à seulement pour but de créer un jeu de Sonic avec les ressources donné.
De l'IA est utilisé pour créer le jeu que ce sois pour des ressources ou le code en lui-même.


Pour toute contribution à ce projet, vous pouvez me contacter sur Discord : mrchoppergt

English - US

Sonic FX is a fan game of the Sonic The Hedgehog.
The project is open source and is available for everyone.
The engine used is under Unity with the source code "The Bumper Engine" of SuperSonic68.

The project only aims to create a Sonic game with the given resources.
AI is used to create the game, whether for resources or the code itself.
